# Phase 14 Frontend Component Catalogue

These components form the basis of the Local Authority Trust display on AME Bazaar.

## Component Index

### `review-card.php`
Displays a review item. Supports star rating output, customer avatar or initial, verified badge checkmarks, purchase categories, review texts, and custom buyer images.

### `review-summary.php`
Shows star breakdown distribution progress bars (5-star to 1-star calculations) along with direct action buttons.

### `review-slider.php`
Creates a responsive review cards carousel. Implemented via pure-CSS scroll snapping for high-performance mobile loading and zero CLS layout shifts.

### `review-badge.php`
Displays an aggregate badge indicating total count and overall score.

### `review-cta.php`
Provides quick-tap CTA buttons (WhatsApp, call, directions, and write review).

### `google-rating-widget.php`
Presents a compact, interactive Google Rating badge style card.

### `trust-block.php`
Focuses on value proposition cards (Tailoring Expertise, 500+ Google Reviews, Genuine Pricing, family store legacy).

### `customer-highlights.php`
Uses interactive tab items to list dynamic, parsed summaries of reviews.

### `popular-review-keywords.php`
Displays keyword tags associated with recent reviews.
